# Security

Please report a security problem privately to smrutiranjansahoopikun@gmail.com with the steps to repeat it, not in a public issue. We'll reply as soon as we can. There is no paid bug bounty.

Download only from [this repository's releases](https://github.com/SMRUTIRANJAN30/vestnil/releases) or https://vestnil.netlify.app, and compare the SHA-256 with `SHA256.txt` in the release. We never ask you to turn off your antivirus.

More: https://vestnil.netlify.app/security
